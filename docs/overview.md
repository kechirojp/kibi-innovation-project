# 全体構想

**状態：市民提案。自治体・企業による採択や投資決定はありません。**

## 目指す循環

倉敷の市民と工場が課題を示し、大学・企業・起業家が解決策を試す。吉備中央町のデジタル施策や将来の計算基盤も実証の場に加える。使える技術や制度は自治体・企業が最初の顧客となり、結果を公開して他地域へ広げる。

「地域の課題 → 公開募集 → 小規模実証 → 効果測定 → 調達・制度化 → 他自治体への展開」を繰り返す。

## 確認済みの事実

- [吉備中央町はデジタル田園健康特区に指定](https://www.chisou.go.jp/tiiki/kokusentoc/shiteikuiki.html)されている。
- [岡山大学のOI-Start](https://oistart.okayama-u.ac.jp/)は、県内の産学官によるデジタル技術の実践と人材育成を掲げている。
- [水島コンビナートでは三菱ガス化学が副生ガス由来メタノールの実証設備を建設](https://www.mgc.co.jp/corporate/news/2025/250324.html)し、2026年度の実証開始を目指している。
- [三菱自動車はロボット企業Highlandersと共同開発・量産検討を発表](https://www.mitsubishi-motors.com/jp/newsroom/newsrelease/2026/20260709_1.html)した。公表された量産候補は京都工場である。

## 提案

| 地域 | 役割案 |
| --- | --- |
| 倉敷市 | 近居支援、プッシュ型行政、製造業AIの実証、市民参加 |
| 水島 | 工場を最初の顧客とする実証、エネルギー・資源循環 |
| 吉備中央町 | 中山間地域での実証、将来のAI計算拠点と用地確保 |
| 大学・企業 | 研究、試作、現場検証、量産・販売 |

## 最初に確かめること

候補地の電力・通信・災害条件、工場の実証需要、自治体の制度・財源、住民の参加意向を測る。土地の取得、大規模設備の建設、補助金の支給は、調査結果と正式な意思決定を経る。
