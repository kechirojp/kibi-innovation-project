# 投稿と個人情報

このサイトは市民の提案を匿名で受け付けます。氏名、メールアドレス、住所を入力する欄はありません。本文にも個人情報を書かないでください。

## 受付から公開まで

1. 投稿内容はCloudflare D1に非公開で保存します。受付時に地域、テーマ、タイトル、本文、受付日時、審査状態、識別番号を記録します。
2. 運営者が内容を確認します。個人情報や第三者を特定できる記述、誹謗中傷を除き、提案の要点をGitHub Issueに整理します。すべての投稿を公開するとは限りません。
3. 元の投稿はIssueへの転記後、または受信から90日以内に削除します。連絡先を取得しないため、投稿者への個別回答や削除通知はできません。

不正な大量投稿を抑えるためCloudflare Turnstileを使います。Turnstileの検証結果だけを受付処理に使用します。サイト運営にはCloudflareの標準的な通信記録が発生する場合があります。

公開Issueは誰でも読めます。公開された提案に個人情報が残っている場合は、GitHub Issueでお知らせください。運営者が確認して修正します。

このプロジェクトは市民による構想であり、自治体や企業の公式な申請窓口ではありません。緊急の相談や行政手続には、各機関の正式な窓口をご利用ください。
