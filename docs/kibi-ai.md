# 吉備中央町のAI基盤

**状態：用地・受電・事業者は未決定。**

## 確認済みの事実

- [吉備中央町はデジタル田園健康特区](https://www.chisou.go.jp/tiiki/kokusentoc/shiteikuiki.html)である。
- [賀陽ICは岡山自動車道](https://www.town.kibichuo.lg.jp/site/kanko/48.html)にある。
- [鳴滝ダム](https://www.pref.okayama.jp/page/480265.html)は治水・水道用水などを目的とする。県の概要には発電設備の記載がない。
- 国は[データセンターの立地を電力と通信の両面から考える方針](https://www.enecho.meti.go.jp/about/whitepaper/2025/html/1-2-2.html)を示している。

## 提案

AI向けデータセンターと将来の増設に備える候補地を調べる。敷地だけでなく、受電設備、送電経路、複数の通信回線、冷却、災害対応を一体で計画する。事業者への公開情報提供依頼を行い、必要電力と投資規模を比較する。

鳴滝ダムは放流量と落差から小水力の可能性を調べる。ペロブスカイト太陽電池と縦型風車は発電量を実測する。これらの電源が担える範囲は、計測後に決める。

## 実証で確かめること

候補地ごとの受電可能容量、接続までの期間、通信遅延、災害リスク、冷却に使う水・電力、設備増設費、町内の雇用・税収への効果。既存の住民サービスとデータセンターの電力需要を競合させない計画を作る。
