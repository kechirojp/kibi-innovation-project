# 水島のエネルギー・資源循環

**状態：既存実証との接続を提案。追加プラントの投資決定はありません。**

## 確認済みの事実

- [三菱ガス化学](https://www.mgc.co.jp/corporate/news/2025/250324.html)は、水島工場で副生ガスと水素を用いる年産100トン規模のメタノール製造実証を計画している。
- [水島港](https://www.pref.okayama.jp/page/detail-43085.html)は高梁川河口部に位置する。
- [福岡市](https://www.city.fukuoka.lg.jp/shisei/kouhou-hodo/hodo-happyo/2025/documents/nihonhatsushintouatsuhatsudenshisetsuuntenkaishinooshirase.pdf)は下水処理水と濃縮海水による浸透圧発電を開始し、正味約110kWを見込んでいる。水島で同じ出力が得られるという意味ではない。
- [銅・鉄光触媒とLEDによるアンモニア分解](https://pubmed.ncbi.nlm.nih.gov/36423268/)は研究で示されている。
- [倉敷市の施設資料](https://www.city.kurashiki.okayama.jp/kurashi/suidou/1003847/1013212/1003903.html)には、児島・玉島下水処理場の汚泥消化槽が記載されている。

## 提案する実証

1. 水島の工場・発電設備の時間別電力需給を測り、余力が出る時間帯と用途を調べる。
2. 副生ガス・CO₂・水素を活用する燃料製造を既存の実証と連携して検討する。
3. 処理水と海水の塩分差による浸透圧発電を、放流地点と水質の調査から始める。
4. 汚泥消化液からアンモニアを回収し、LED光触媒で水素に変える小型試験を下水処理場とコンビナートで比較する。
5. ペロブスカイト太陽電池と樹形の縦型風車は実測型の先行導入を検討する。

## 実証で確かめること

各設備の正味発電量・消費電力・運転費・耐久性・水質への影響。合成燃料の製造は電力を使うため、電力が余る時間に製造量を増やす運用を評価する。AIデータセンターへの供給は、発電量と系統接続の確認後に判断する。
